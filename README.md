# ATM-SIMULATOR

## Overview

ATM Simulator is a front-end banking simulation project designed to replicate the workflow of a real Automated Teller Machine (ATM). The application demonstrates transaction processing, balance management, receipt generation, user authentication, and screen-based navigation using HTML, CSS, and JavaScript.

The project was originally developed as a personal learning exercise focused on JavaScript state management, UI transitions, and transaction workflows.
---
## Project Recovery Note

The original source code for this project was lost due to a storage failure. The current repository has been reconstructed using a recorded demonstration of the application and available project artifacts.

The reconstruction preserves the original user flow, interface structure, and core functionality demonstrated in the recorded build, including account balance tracking, transaction processing, receipt generation, and ATM navigation screens.

This repository serves both as a recreation of the original project and as documentation of the application's design and functionality.
